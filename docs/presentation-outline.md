# Presentation Outline

## Slide 1 - The Photo Problem

Bullets:

- Photos preserve the outside of a moment.
- The lost part is internal: attention, emotion, body state, meaning.
- Thesis: photos record what we saw; brain-state replay asks whether we can reconstruct what we were.

Speaker notes:

Start with a familiar problem. A photo can show a birthday, a trip, or a person, but it cannot restore what it felt like to be that version of yourself. This project starts from that gap.

## Slide 2 - What Is a Moment?

Bullets:

- Not an image file or single memory slot.
- Distributed brain-body state: sensory, hippocampal, emotional, interoceptive, attentional.
- Remembering is reconstruction in the present.

Speaker notes:

Define the unit of the project carefully. A moment is a state across systems, not a photograph in the brain. Any replay would be partial and reconstructed through the current self.

## Slide 3 - Plasticity as the Native Record

Bullets:

- Experience changes synapses and circuit dynamics.
- LTP/plasticity are part of the biological memory substrate.
- No previous external brain-state recording is strictly required.
- Hard problem: retroactive addressability and controlled reactivation.

Speaker notes:

This is the refined pivot. The project is not saying we need to have recorded your brain during the original moment. The nervous system already carries traces. The challenge is finding and safely reactivating the right trace.

## Slide 4 - Three Replay Modes

Bullets:

- Realistic floor: cue-triggered recall and Targeted Memory Reactivation.
- Frontier: direct engram reactivation.
- Frontier: guided endogenous replay without a simple external trigger.
- All modes are partial state nudges, not exact playback.

Speaker notes:

Cue-triggered recall is familiar: songs, smells, places, photos. TMR is the research-adjacent version, where paired cues bias reactivation. Direct engram and guided endogenous replay are the speculative frontier.

## Slide 5 - EEG Helps, But Has Limits

Bullets:

- EEG is non-invasive and temporally useful.
- It can track broad state correlates.
- It cannot read synaptic traces or directly identify engrams.
- It cannot provide exact visual memory playback.

Speaker notes:

This slide protects the science. EEG might support state monitoring, sleep staging, attention tracking, or feedback. It is not a microscope for LTP, and it is not a memory video decoder.

## Slide 6 - Current Repo Simulation and Data

Bullets:

- Conceptual target states: calm, autobiographical memory, flow, emotional memory.
- Protocols model cueing, neurofeedback, DBS-like modulation, and MIMO-inspired correction.
- Metrics: similarity, reconstruction error, safety risk.
- Synthetic data and tests make assumptions explicit.

Speaker notes:

The demo is a supporting artifact. It does not prove real neuroscience. It demonstrates that the concept can be expressed as state vectors, intervention assumptions, and safety-aware evaluation.

## Slide 7 - Scientific Boundaries

Bullets:

- No literal time travel.
- No medical claim or therapeutic effect.
- No exact human memory replay.
- No exact visual playback.
- No claim that EEG reads synaptic traces.

Speaker notes:

Be explicit about what the project is not. The credible version is a framework for partial state reconstruction and controlled reactivation, not science fiction presented as current capability.

## Slide 8 - Roadmap and Ethics

Bullets:

- Build a clearer literature map and citation table.
- Add attractor-state and synthetic EEG-like models.
- Keep simulation secondary to the thesis.
- Ethics: consent, identity, emotional risk, false memory, manipulation.

Speaker notes:

Close with why this matters. If a system can influence recall intensity or state re-entry, safety and consent are core design requirements. The next step is stronger foundations before richer interaction.
