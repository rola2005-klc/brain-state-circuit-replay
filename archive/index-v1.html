Speculative neuroscience and BCI foundation

Brain-State Circuit Replay

Photos record what we saw. This project asks whether future interfaces could reconstruct what we were.

A presentable thesis about partial brain-body state reconstruction, not literal time travel, medical software, exact memory replay, or visual playback.

Core idea

The memory trace is already biological.

A meaningful moment is not just an external image. It is a distributed state involving sensory fragments, hippocampal context, emotional salience, body feeling, attention, and interpretation.

The refined hypothesis is that no previous external brain-state recording is strictly required. Plasticity and LTP are the native biological record; the hard problem is retroactive addressability and controlled reactivation.

Scientific boundary

  • EEG is a non-invasive state correlate, not a synaptic trace or engram readout.
  • The realistic floor is cue-triggered recall and Targeted Memory Reactivation.
  • The frontier is direct engram reactivation and guided endogenous replay.
  • The goal is partial state approximation, not exact human memory playback.

Conceptual framework

The project is foundation-first: define the science, then use the demo as supporting evidence.

TraceExperience leaves plasticity-based changes in distributed circuits.
AddressCues, context, sleep, attention, or future stimulation try to access the right trace.
ReactivateThe current brain-body state is nudged toward a remembered state region.
SafeguardSimilarity, uncertainty, distortion, and emotional risk must remain visible.

Presentation-ready story

Photo problem: A photo records the outside of a moment. Brain-State Circuit Replay asks whether we can also reconstruct the inside of a moment: perception, emotion, body sensation, attention, and meaning.

Current focus: The repo is building the conceptual and scientific foundation first. The simulator below is a supporting conceptual demo, not the main product and not biological validation.

  1. Known: plasticity, memory traces, cue-triggered recall, and Targeted Memory Reactivation.
  2. Plausible: closed-loop cueing and feedback that bias partial state re-entry.
  3. Speculative: direct engram reactivation or guided endogenous replay of a specific past state.
